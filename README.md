# MyCodery

Private, instance-specific companion to
[Codery](https://github.com/CoderyOSS/Codery) — what this deployment adds on
top of the product: inventory, deployment config, and instance history.

- Product source and docs → `CoderyOSS/Codery` (cloned at `/workspace/Codery`)
- This deployment's inventory → [`INSTANCE.md`](INSTANCE.md)
- Operating guide for the VPS → Codery's `RUNBOOK.md`

No fork: this repo does not share history with Codery and contains no Codery
source. Update Codery by pulling its public repo; record deployment-specific
facts here.
